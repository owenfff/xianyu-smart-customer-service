万达旅游客服｜Windows 精简本地运行包

一、安装前准备
1. Windows 10/11 64 位
2. Python 3.11
3. Node.js 16 或更高版本（部分 JavaScript 处理需要）
4. 能正常访问网络

二、安装
双击 install-windows.bat，等待依赖安装完成。

三、启动
双击 start-local.bat，然后打开：
http://localhost:9000

四、保留的核心功能
闲鱼账号、聊天、AI 回复、关键词回复、商品/SKU、RAG 知识库、必要通知、用户管理。

五、精简内容
安装包不包含 Docker、测试文件、调试文件、开发文档、历史日志、备份、旧浏览器登录状态和账号 Cookie。
自动好评、自动求小红花、商品发布等非第一阶段文件不放入此运行包。

六、数据迁移
本包默认是空数据，第一次启动后请在页面配置账号和 AI。
如需迁移产品和 RAG 知识库，请从原电脑的数据管理页面导出后，在新电脑导入。
不要直接复制或公开 Cookie、Token、账号密码。

七、注意
同一闲鱼账号不要同时在两台电脑运行，否则可能互相抢登录状态。
滑块验证沿用项目原有处理逻辑，没有在此安装包中修改。
