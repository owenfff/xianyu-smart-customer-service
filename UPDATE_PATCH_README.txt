万达旅游客服｜卡片与人工提醒更新补丁

使用方法：
1. 先关闭旧版本窗口或停止旧服务。
2. 把压缩包里的文件解压到原程序文件夹，选择“覆盖”。
3. 不要删除原文件夹里的 data、browser_data、global_config.yml 和 logs。
4. 重新运行 start-local.bat；Docker 用户在项目目录执行 docker compose restart。

本次更新：
- 酒店价格卡片改为宽卡片自适应布局，房型、价格、备注列不再挤在一起。
- 修复仪表盘和资料库的深色模式，避免出现白底白字。
- 修复深色模式下侧边栏仍显示紫色的问题，使侧边栏与深色客服工作区统一为深蓝色。
- 实时房态、下单/预订、入住/到店、退款/取消/改期等需要实际确认的问题，只提醒人工，不向客户发送机器人占位消息；AI只做前置接待。
- 客服案例只作为表达训练语料，不作为固定模板，也不会覆盖当前价格和房态。
- 本补丁不覆盖数据库，因此不会覆盖其他电脑现有的账号、Cookie、商品、RAG 和通知配置。
- 随便打开哪个闲鱼商品都可以测试酒店问题；“枕水/通安/乌镇/堤上”等酒店问题会优先查全局酒店 RAG，不会被当前闲鱼商品标题和 SKU 干扰。
- 修复酒店连续追问：客户上一句提到“枕水/通安”等酒店，下一句只问“9.12 呢”时，会继承酒店上下文并继续查对应价格；通安/枕水周五周六会按基础价自动加 200 元，中秋、国庆仍转人工确认。
- SKU 未能唯一匹配时，如果当前闲鱼商品标题明确是枕水/通安等酒店，价格或房型问题会自动降级使用对应酒店 RAG；唯一匹配的 SKU 仍优先按商品 SKU 回复。
- 计算规则只在后台用于算价，客户消息中不展示“基础价加 200”等内部计算过程，只显示最终价格。
- 酒店报完参考价格后的结尾统一为：“请问您想订哪种房型呢？我帮您查下房态。”
- 普通问题如果 AI 生成失败，仍按原逻辑提醒人工；需要人工确认的问题不会先发送“请稍等”之类的占位消息。

测试方式：
1. 覆盖补丁后重启服务；Docker 在项目目录执行 `docker compose restart xianyu-app`，本地运行则重新双击 `start-local.bat`。
2. 浏览器按 Ctrl+F5 刷新页面。
3. 从任意闲鱼商品进入聊天，发送“枕水 9.13 多少钱”测试酒店价格资料；无需先配置这个闲鱼商品。
