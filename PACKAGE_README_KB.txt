万达旅游客服 - Windows 本地运行包（带知识库版）

这个版本只带入开发电脑当前的知识库：

- 124 条 RAG 知识，包括酒店价格规则、日期加价规则、常见问答和精炼客服案例
- 不带入任何闲鱼账号、Cookie、商品、SKU或聊天记录
- 已清理运行日志、风控日志和历史任务

出于安全考虑，安装包不会带入以下内容：

- 咸鱼 Cookie、账号密码
- AI API 密钥
- 飞书/钉钉等通知 Webhook

使用方法：

1. 解压到一个没有中文或空格的目录，例如 C:\WandaService。
2. 电脑需要安装 Python 3.11；可在 PowerShell 执行 `py -3.11 --version` 检查。
3. 双击 install-windows.bat，等待依赖安装完成；窗口会保留安装结果。
4. 双击 start-local.bat 启动服务。
5. 浏览器打开 http://127.0.0.1:9000。
6. 登录 admin / admin123；首次登录后请立即修改密码。
7. 在“账号管理”添加或登录咸鱼账号，并在“AI回复”填写 API 密钥。

注意：首次添加闲鱼账号后，系统会自动把这 124 条 RAG 知识绑定到该账号。
之后新增账号也会自动获得这份基础知识库。

客服案例只用于学习真实人工的表达方式，不会作为固定模板原样发送，也不会覆盖当前酒店价格和房态。
